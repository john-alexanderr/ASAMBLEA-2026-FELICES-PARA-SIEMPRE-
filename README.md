# Asamblea 2026 — Felices para siempre

Sitio web informativo para la Asamblea Anual 2026 de los Testigos de Jehová.

## Descripción

Página web desarrollada para proporcionar información útil a los asistentes a la asamblea, incluyendo:

- **Transporte**: Información sobre remises y opciones de movilidad
- **Hoteles**: Alojamientos recomendados cercanos al evento
- **Mapa e Información**: Centros de información y puntos de interés
- **Servicios**: Primeros auxilios, transporte público, comida y más

## Características

- Diseño responsive optimizado para dispositivos móviles
- Efectos visuales modernos con parallax y animaciones
- Navegación suave entre secciones
- Integración con Bootstrap 5 y AOS (Animate On Scroll)
- Efectos 3D con VanillaTilt

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.2.3
- AOS 2.3.1
- VanillaTilt 1.8.1

## Despliegue

El sitio se despliega automáticamente a GitHub Pages mediante GitHub Actions al hacer push a la rama `main`.

## Estructura del proyecto

```
├── index.html          # Página principal
├── css/
│   └── styles.css      # Estilos personalizados
├── js/
│   └── scripts.js      # Lógica JavaScript
├── assets/
│   ├── favicon.ico     # Icono del sitio
│   └── img/            # Imágenes del proyecto
└── .github/
    └── workflows/
        └── deploy.yml  # Configuración de GitHub Pages
```
